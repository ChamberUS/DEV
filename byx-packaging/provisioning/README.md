# Provisioning de DESENVOLVIMENTO (Personal Team)
`provision.sh` gera `out/service.provisionprofile` (ignorado pelo git) pelo mecanismo normal do Xcode (conta já logada; nenhuma credencial é lida ou guardada aqui). **Ação persistente na conta Apple:** cria/atualiza o App ID explícito `com.buynnex.byx.service` e um perfil de desenvolvimento macOS, e registra ESTE Mac como dispositivo. Pede só `application-identifier` e `team-identifier`.
**Personal Team = temporário:** o perfil vale 7 dias (criado 2026-10-06, expira 2026-10-13 16:49:55 UTC). Reprovisionar: `./provision.sh` e depois `./build-app.sh --embedded-profile provisioning/out/service.provisionprofile`. Vencido o perfil, o helper do serviço é encerrado pelo macOS e o armazenamento fica `NOT_CONFIGURED` (nunca texto puro). **Somente desenvolvimento; não é estratégia de distribuição** (exige Developer ID + perfil de distribuição, notarização e canal de atualização).
Ver `../../byx-local-service/docs/SECURE_SECRET_STORE.md`.
